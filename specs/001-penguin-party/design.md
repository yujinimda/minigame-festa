# 설계 문서: 미니게임 페스타 — 펭귄 빙판 걷기 (001)

**작성일**: 2026-08-21
**단계**: 1. 아이디어 → brainstorming 산출물 (대화 기반 확정)

## 무엇을 만드나

오프라인에 모인 최대 15명이 즐기는 웹 파티게임. 마리오파티/Jackbox 스타일 —
큰 화면(호스트)에 QR을 띄우고, 참가자는 폰으로 QR을 찍어 들어와 컨트롤러로 조작,
큰 화면에서 다같이 레이스를 보며 순위를 가린다.

## 왜 이 접근인가 (브레인스토밍에서 검토·확정된 결정)

### 화면 구조 — Jackbox 방식 (확정)
- **호스트 화면(큰 화면)**: QR + 로비 + 게임 진행(레이스 뷰) + 순위 표시
- **플레이어 화면(폰)**: QR 스캔 → 닉네임 입력 → 컨트롤러 역할 (입력 전담)

### 네트워크 — 서버리스 P2P (확정)
검토한 대안: ① PeerJS P2P ② Socket.io + 무료 서버(Render 등) ③ Supabase Realtime

**① P2P 채택.** 이유:
- 호스트 브라우저가 서버 역할 → 백엔드 불필요, 유지비 0원
- 정적 호스팅(Vercel 무료) + PeerJS 공식 시그널링 서버(무료)만으로 동작
- 15명 규모에 충분하고, 서버 경유보다 지연이 적어 리듬/타이밍 게임에 유리
- 단점 수용: 호스트 브라우저를 끄면 방이 사라짐 — 파티게임 특성상 허용

### 판정 위치 — 클라이언트 로컬 (확정)
기울기/거리 계산·판정은 플레이어 폰에서 로컬로 수행, 상태(거리·기울기·넘어짐)만
초당 수 회 호스트로 전송. 지연 민감도를 낮추고, 지인끼리 플레이라 치팅 리스크 수용.

### 첫 미니게임 — 펭귄 빙판 걷기 (확정)
후보(폭탄 돌리기, 무궁화 꽃, 의자 뺏기, 살얼음 밟기, 요리 주문, 풍선 불기) 중
"아기자기 + 스릴 + 폰 입력 적합성"으로 펭귄 걷기 선택.

**게임 규칙 초안**:
- 폰의 좌/우 버튼을 번갈아 탭 → 펭귄 전진
- 같은 쪽 연속 탭이나 박자가 깨지면 기울기 누적
- 기울기 게이지 한계(±100) 초과 → 꽈당, 기록 확정 (빙판 위를 주르륵 미끄러지는 연출)
- 제한시간 30초 내 최대 거리 경쟁
- 호스트 화면: 가로 트랙에 펭귄들이 나란히 달리는 레이스 뷰 + 실시간 거리 순위

**밸런스 로직 초안**:
- 좌우 교대 성공 → 전진 + 기울기 살짝 회복
- 같은 쪽 두 번 → 그 방향으로 기울기 급증
- 입력 텀이 길어짐 → 기울기가 서서히 랜덤 방향으로 흐름 (빙판 컨셉)

### 기술 스택 (확정)
- Next.js 단일 프로젝트: `/host` (큰 화면), `/play/[roomId]` (폰)
- PeerJS(WebRTC): 호스트가 방을 열고 roomId를 QR로 표시, 플레이어가 직접 연결
- 배포: Vercel 정적/프리뷰 (무료)
