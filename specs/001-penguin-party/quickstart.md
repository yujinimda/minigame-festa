# Quickstart: 펭귄 빙판 걷기 검증 가이드

## 사전 조건

- Node.js 24+, npm
- 폰 실기기 테스트 시: 폰과 개발 머신이 같은 네트워크 (또는 Vercel 프리뷰 URL 사용)

## 실행

```bash
npm ci
npm run dev        # http://localhost:3000
```

## 검증 시나리오

### 1. 참가 동선 (US1)

1. 데스크톱 브라우저에서 `/host` 열기 → QR + 방 코드 표시 확인
2. 폰(또는 모바일 뷰포트 탭)에서 QR 스캔 → `/play/{roomId}` → 닉네임 입력
3. 3초 내 호스트 로비에 닉네임 표시(AS2), 같은 닉네임 재입장 시 " (2)" 접미사
4. 16번째 입장 시도 → "정원 초과" 거부(AS3)

### 2. 레이스 (US2)

1. 2명 이상 입장 후 호스트 "시작" → 폰 컨트롤러 전환 + 3초 카운트다운
2. 좌/우 교대 탭 → 호스트 화면 펭귄 전진(0.5초 내 반영, SC-002)
3. 같은 쪽 연타 → 기울기 급증 → 넘어짐 + 미끄러지는 연출 + 기록 확정
4. 입력 중단 → 기울기 서서히 드리프트
5. 30초 경과 → 결과 화면 전환

### 3. 순위·다시 하기 (US3)

1. 호스트에 거리 내림차순 순위, 폰에 개인 기록·등수
2. "다시 하기" → 같은 멤버로 로비 복귀 → 재시작 가능

### 4. 엣지

- 레이스 중 폰 새로고침 → 같은 닉네임으로 자동 재접속(승계)
- 레이스 중 새 QR 입장 → "게임 진행 중" 차단
- 호스트 탭 닫기 → 폰에 "방이 종료됨"

## 테스트

```bash
npm run test       # Vitest — 게임 로직·프로토콜·로스터 규칙
npm run e2e        # Playwright — 호스트+플레이어 2명 스모크 (dev 서버 자동 기동)
npm run lint && npm run build
```
